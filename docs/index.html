Vagas

Busca de empregos de .NET e C# na Grande São Paulo, na região de Sorocaba e no remoto. A lista abre no seu computador, com local, salário, stack e o link para se candidatar.

Código no GitHub Como abrir

O que ela faz

Todo dia, ao abrir

O programa consulta a listagem pública do LinkedIn e mostra as vagas novas na tela. O console acompanha cada página.

Três regiões

Grande São Paulo, Sorocaba e cidades ao redor, e vagas remotas anunciadas para o Brasil.

Informação já separada

Local, modalidade, salário quando o anúncio publica, senioridade, contrato, stack e onde se candidatar.

Sem vaga repetida

Ocultar tira a vaga da mesa. Dá para marcar salva, candidatura, entrevista, oferta ou recusa.

Como abrir no seu computador

A busca roda aí, num programa .NET. Esta página só apresenta o projeto.

git clone https://github.com/lcarlini/AIJobSearchAggregator.git
cd AIJobSearchAggregator
./run.ps1

O navegador abre em http://localhost:5088.

Fonte

A primeira fonte é o LinkedIn, pela listagem pública, sem login. Outra fonte entra implementando IJobSource.
